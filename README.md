# Mobile To-Do Application – Module 2

A beginner-friendly mobile To-Do application built with React Native and Expo.

## Features
- Home screen with task list
- Add Task screen
- Categories: Personal, Study, Work
- Task completion checkbox
- Delete tasks
- Basic input validation
- Multi-screen navigation

## Run
1. Install Node.js.
2. Install Expo CLI / use `npx expo`.
3. Run `npm install`.
4. Run `npx expo start`.
5. Test using an Android emulator or Expo Go.
